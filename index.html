Dice Entropy Check

Fairness test for dice used in Bitcoin seed generation · v1.0 · runs fully offline
Test rolls only. Never enter the rolls you will use for a real seed, here or in any other tool. This page tests whether a die is fair. Roll it separately when you generate your seed.

Setup

How strict the test is. It is the chance of failing a die that is actually fair: at 0.05, about 1 in 20 fair dice will fail just by bad luck. 0.01 means fewer false alarms, but a bad die needs a bigger bias (or more rolls) before it gets caught. 0.10 catches problems sooner but fails more fair dice. 0.05 is the standard choice. The per-bit test splits this level across the bits (α ÷ 4 on a D16).

Chi-square Measures how uneven the counts are. For each face it takes (observed − expected)² ÷ expected, then adds them up. 0 would be a perfectly even spread. A fair die usually lands somewhere near the degrees of freedom (df = sides − 1, so about 15 on a D16). The further above that, the more uneven the counts.
–
p-value The chance that a perfectly fair die would produce results at least this uneven. A high value (say 0.65) means your results look like ordinary randomness. A value below α (e.g. 0.05) means a fair die would do this less than 5% of the time, so the die is flagged. It is not the probability that your die is fair.
–
Detectable bias Roughly the smallest skew in a single face that your current number of rolls would reliably catch (about 80% of the time at the 5% level). Smaller is better. Quadrupling the number of rolls cuts this number in half.

Verify this page

Don't trust, verify. Here is what you can check yourself:

  1. It's one file. All the logic is in this one page: no external scripts, fonts or libraries. Open it in a text editor and read it; the logic is a few hundred lines of plain JavaScript in the <script> block at the bottom. The installable version adds only an icon, a small manifest, and sw.js, a ~50-line script that stores the app's own files for offline use.
  2. Network access is blocked by the browser. The Content-Security-Policy tag at the top sets default-src 'none', so the browser refuses any fetch, XHR, WebSocket, beacon, font or form submission, even if code tried one. The only exceptions are the app's own icon, manifest and sw.js, from the same site. CSP does not cover a page navigating itself to a new address, so also confirm the code never assigns to location, calls window.open, or links to outside sites. Search for http: apart from this text and the http-equiv tag itself, the only match is a check that the page is served over https before offering offline install.
  3. Test it offline. Save the file (or install the app), turn on airplane mode or unplug your network, and open it. Everything works.
  4. Check the hash. Compare the file's SHA-256 against the hash the author published and signed: 
    shasum -a 256 dice-entropy-check.html        # macOS / Linux
certutil -hashfile dice-entropy-check.html SHA256   # Windows
    The downloadable file and the website's index.html are byte-for-byte the same, so they share one hash.
  5. Check the math. Use Download rolls (CSV) and run the same chi-square test in any stats tool, e.g. Python: scipy.stats.chisquare(counts).

How to use it

  • Roll the die the same way you'll roll it for real (same surface, same cup or tray), and tap the face that comes up. On a keyboard you can type the face as a hex digit instead (e.g. b for 1011).
  • The minimum is 10× the number of sides (160 rolls for a D16). That only catches large problems. More rolls detect smaller biases; the Detectable bias tile shows roughly how large a skew your current sample would reliably catch.
  • The chi-square test asks whether the spread of results is consistent with every face having equal probability. A p-value below α means the result would be unusual for a fair die. At α = 0.05, about 1 in 20 fair dice will still fail by chance, so re-test a die that fails before discarding it.
  • A single run passing does not prove a die is perfect. It means no bias large enough to detect at that sample size was found.
  • Install it as an app (when opened from the website): on iPhone or iPad, tap Share, then Add to Home Screen. On Android or desktop Chrome/Edge, use Install app in the browser menu. After the first visit it works with no connection.
